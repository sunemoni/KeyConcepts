# Key Concepts Construction

Source and photo assets for the Key Concepts Construction website.

Live site: https://key-concepts-construction.sunemoni.chatgpt.site

## Development

Install dependencies with `npm ci`.

This project uses React, Vinext, and Cloudflare Workers with D1 storage. Site deployment configuration is in `.openai/hosting.json`.

Contact submissions are stored in the deployed database; automatic email notifications are not configured yet. Runtime secrets and database contents are not included in this repository.
